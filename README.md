Написанные тесты для приложения BooksCollector
1.1 Добавление 2х новых книг без указания жанра
1.2 Книга с недопустимым количеством символов в названии не добавляется
2. Устанавливание жанра книге
3. Получение жанра книги по названию книги
4.Вывод списка книг с определенным жанром
5. Получение названия книги и ее жанра в виде словаря
6. Книги с возрастным рейтингом отсутствуют в списке книг для детей
7. Книга добавляется в список избранного
8. Нельзя повторно добавить одну и ту же книгу в избранное
9. Удаление книги из избранного
10. Получение списка книг в избранном для 3х книг

Фикстуры:
1.1 Создание экземпляра для тестов 1-10
1.2 Создание книги для тестов 2-7
2. Создание книги и добавление ее в избранное для тестов 8-9
3. Создание книг и добавление их в избранное для теста 10

Параметризация:
В тесте 1.2 выполнена параметризация для тестирования недопустимого для добавления в подборку названия книги
